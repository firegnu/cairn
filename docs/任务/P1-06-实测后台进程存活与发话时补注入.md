## 要做的

1. 在 `p1-lab/bgprobe/` 里写一个 Rust 小探针（独立的 cargo 项目，编译目录也放在 `p1-lab/bgprobe/` 里）。Stop hook 调它时，它起一个脱离会话的子进程就马上返回：子进程新开一个会话（`setsid`，DESIGN §8.8 的写法），标准输入、输出、错误都接到 `/dev/null`。子进程每 20 秒往日志追加一行（自己的 PID、父 PID、时间），一共坚持 5 分钟后退出。hook 自己记下从被调用到返回用了多久。
2. UserPromptSubmit hook 输出 JSON 格式的 `hookSpecificOutput.additionalContext`，内容是一个合成口令。
3. 两家各开 2 个测试会话。每个会话发两句话：第一句随便做件不弹权限框的小事（让 Stop 触发一次）；第二句让它“如果上下文里有 hook 补充的口令，原样复述，没有就说没有”。然后关掉会话：一个用正常退出（在会话里输入退出命令），一个用 `corral stop`。
4. 关掉之后等子进程的 5 分钟走完，看日志：会话关掉之后它还写了多久，父 PID 有没有变。

报告写短：工具版本和日期；方法（几句话）；两家各自的结果：hook 多久返回、两种关法之后子进程活了多久、补注入的口令有没有被复述出来；每条结果属于“已查证”“推测”还是“未知”；实际开了几个测试会话；这次在实验目录和工具配置里新留下的东西的清单（包括 Codex 的 hook 信任记录，写明怎么清除）。不写 cairn 该怎么设计。
