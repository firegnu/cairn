## 测试会话

- **一共只开 2 个：Claude Code 一个，Codex 一个。** 某一个没杀在回合中途（比如回合已经结束了才杀到），可以重做一次；总数不超过 4 个，报告里写明实际开了几个。
- 用 corral 开：`corral start cairn/test-<名字> --unique --cwd <p1-lab 下的仓库> --label role=test --env CAIRN_DISABLE=1 -- <claude 或 codex 及参数>`。
- 模型：Claude 用 `--model sonnet --effort medium`，Codex 用 `-m gpt-5.6-luna -c 'model_reasoning_effort="medium"'`。Claude 的额度紧，每个会话只发一个回合。
- 用默认权限和默认沙箱，不加 `--yolo`、`--dangerously-skip-permissions` 这类参数。回合里的步骤选不弹权限框的操作（比如逐个读合成文件）；弹了框就换步骤重来，不要用 `corral keys` 去点。Codex 的项目级 hook 没有持久信任时，可以对自己的测试会话加 `--dangerously-bypass-hook-trust`，报告里写明。
- 强杀只对自己开的测试会话：用 `corral status <名字>` 给出的 `agent_pid`，`kill -9` 这一个 PID。杀完 `corral stop <名字>` 收掉。任务结束时 `corral ls` 里不能再有你开的。
- `corral ls` 里其他的 agent 都不是你的：不要对它们执行 `stop`、`send`、`keys`，也不要 attach。
- 需要用户点信任对话框时：不要替他点。在回复里写清 agent 名字、要点的是什么、点完怎么断开、这条信任以后去哪里清除，回复最后一行写 `WAIT-USER`（不是 DONE），结束本轮。
